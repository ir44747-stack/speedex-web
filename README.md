# SPEEDEX — China → Qatar (interactive prototype)

Immersive React + Three.js + GSAP + Tailwind website for SPEEDEX:
3D Beijing→Doha flight pre-loader · trilingual EN/AR/中文 (RTL) · dark/light ·
Beijing↔Doha compare · Shipment Planner · Blueprint→Reality corporate setup · RFQ form.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```
